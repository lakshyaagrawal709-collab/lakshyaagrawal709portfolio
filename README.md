## ⚙️ Local Installation & Running

1. **Navigate to the project folder**:
   ```bash
   cd C:\Users\laksh\.gemini\antigravity\scratch\lakshay-portfolio
   ```

2. **Install Node.js dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server on Port 3030**:
   ```bash
   npm run dev -- --port 3030
   ```
   Or double-click `run-portfolio.bat`!

4. **Build production bundle**:
   ```bash
   npm run build
   ```
